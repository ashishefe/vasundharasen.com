How to read this dashboard — the rules behind every claim

Every rendered claim carries its sources

The numbered chips (e.g. 12) link into the Source Ledger, which links out to the public document itself. A claim without a public source does not appear here at all — it sits in the data store, held back, until one exists.

Fact and analysis are visibly separated

Sentences that interpret — rather than report — carry an analysis badge. Interpretation is the point of this product, but it is never dressed up as fact.

Confidence is graded

Parameters resting on official instruments are tagged confirmed; figures that so far exist only in reputable press reporting are tagged reported and treated as provisional.

Editions preserve memory

Each dated edition is a cut of the landscape. "What moved this edition" is the changelog; the track dossiers keep the full dated event trail, so the story never resets between briefings.
